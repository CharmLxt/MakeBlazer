MakeBlazer. Версия 99.26.1. Автор CharmLxt (PyPI: CharmLxt, email: reception.mailspypi@gmail.com).



MakeBlazer — это сверхбыстрая и легковесная локальная машина времени для ваших файлов. Это децентрализованная альтернатива Git, созданная для разработчиков, писателей и дизайнеров, которым нужно мгновенно делать резервные копии проектов без сложных команд. Библиотека работает без единой сторонней зависимости, используя только стандартную библиотеку Python.



Суть работы MakeBlazer заключается в создании снапшотов (снимков) текущего состояния папки. При создании снимка библиотека сканирует все файлы, игнорируя те, что указаны в файле .blazerignore (по умолчанию там скрыты служебные папки вроде \_\_pycache\_\_ или .venv). Для каждого файла вычисляется уникальный SHA-256 хэш, и если файл изменился, его копия сохраняется в скрытую папку .blazer. Это позволяет экономить дисковое пространство, не дублируя одинаковые файлы.



В версии 99.26.1 функционал был значительно расширен. Помимо создания снимков и восстановления отдельных файлов, вы можете делать полный откат всей директории до выбранного снапшота. Встроенный модуль Diff позволяет сравнить текущую версию файла с тем, что было сохранено ранее (изменения подсвечиваются зеленым и красным цветами). Также доступна сборка мусора (Garbage Collector), удаляющая осиротевшие объекты, и экспорт любого снапшота в ZIP-архив.



Главная особенность MakeBlazer — это мягкая интеграция с библиотекой CharmPkk. Если CharmPkk установлен, интерфейс превращается в красочный дашборд: история снапшотов и diff-сравнения отрисовываются в виде красивых таблиц и цветных блоков. Если CharmPkk не установлен, библиотека работает автономно на чистом print, сохраняя весь свой функционал.



Для установки используйте команду pip install makeblazer. Для интеграции с красивым интерфейсом CharmPkk используйте pip install "makeblazer\[charm]". После установки в системе появится консольная команда makeblazer, открывающая интерактивное меню.
